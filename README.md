# Конструктор иллюстраций Figma · 0.2

## Запуск
1. В Figma Desktop откройте рабочую копию: https://www.figma.com/design/JYkzetJMeCPbdE5jR5pXhE/
2. Меню Figma → Plugins → Development → Import plugin from manifest… → dist/manifest.json в этой папке. Если плагин уже импортирован, повторный импорт не нужен.
3. Plugins → Development → Конструктор иллюстраций.
4. Выберите 1–6 объектов, главный акцент, роли, формат, детализацию S/L и палитру. Нажмите «Собрать 3 варианта».
5. На существующей странице «Примеры композиций» появятся три редактируемые рамки: собранная группа, диагональный вариант и вариант с местом под заголовок. Первая рамка выделяется автоматически.
6. Передвигайте, поворачивайте и дублируйте объекты обычными инструментами Figma. Для перекраски выделите рамку и нажмите «Применить к выделенной композиции» — положение объектов сохраняется.
7. Выделите одну рамку и нажмите «Скачать выделенную рамку · SVG».

Для локального плагина платная Figma не требуется. Лимит обращений подключения Figma для агента — отдельное ограничение Starter, которое не относится к кнопке сборки в этом плагине.

## DeepSeek
Без ключа работают сборка по объектам и ограниченный словарь тем. Для свободных смысловых запросов:
1. Скопируйте .env.example в .env и вставьте ключ после DEEPSEEK_API_KEY=.
2. Запустите start-ai.cmd. Окно сервера должно оставаться открытым.
3. Откройте созданный файл .local-token, скопируйте код в поле «Подключение DeepSeek» в панели. После перезапуска сервера код меняется.
4. Нажмите «Проверить сервер». В режиме «По теме» включите DeepSeek и нажмите «Подобрать объекты».

Сервер использует deepseek-flash, если DEEPSEEK_MODEL не указан. Мастер-промпт server/master-prompt.txt подключён к серверу: обычно выбирает 2–4 объекта; первый — главный смысловой акцент. Ответ проверяется по каталогу, включая исключения. Для неподдерживаемых тем подбор возвращает пустой список.
API расходует баланс DeepSeek. Провайдеру передаются только тема и 10 названий объектов с тегами. SVG, изображения и остальное содержимое Figma не передаются. Ключ остаётся в .env на компьютере и отсутствует в архиве/Git.

## Палитры
Три исходные схемы: Лаванда, Персик, Мята. Для новой палитры загрузите examples/palette.json или аналогичный JSON с name и восемью HEX #RRGGBB.
Порядок цветов: светлый фон, средний фон, тёмный фон, основной акцент, второй акцент, светлый акцент, контур, белый.
Проверены фактические цвета всех 40 библиотечных вариантов; фоновым объектам назначаются только три фоновых цвета. Цветовые роли сохраняются отдельно от HEX, поэтому последующая перекраска работает и после пользовательской палитры с повторяющимися цветами.

## Примеры
- examples/01-learning-wide.svg — книга, лампа, ручка; L; 1200×675; Лаванда.
- examples/02-finance-square.svg — кошелёк, монета, фоновая папка; S; 1080×1080; Мята.
- examples/03-creative-portrait.svg — цветы, ручка, фоновые наушники; L; 1080×1920; Персик.

## Разработка и ограничения
Node.js 22.16+, сторонние пакеты не нужны. Сборка: node build.js. Проверка: node --test tests/*.test.js. Сервер: node server/index.js.
Каталог содержит ID объектов именно этой рабочей копии. При смене исходного файла/ID обновите src/catalog.json.
Новые страницы и новые иллюстративные формы не создаются. Общий масштаб сохраняет относительные размеры исходных объектов. Автораскладка даёт отправную композицию; художественная доработка доступна вручную в Figma.
Локальный подбор тем использует ограниченный словарь. Его русские отрицания покрывают обычные конструкции, но не являются полным разбором естественного языка.
Исходники: https://github.com/GMANCO77/figma-illustration-composer (приватный репозиторий). Видеозапись пока не подготовлена. Исходники и инструкция входят в архив; сценарий демонстрации — examples/Демонстрация.md.
