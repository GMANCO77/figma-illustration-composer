# Проверка веб-версии

Проверено 20 ноября 2026 года по времени Бангкока.

- 26 автоматических проверок: названия со склонениями, неизвестные предметы, исключения, три варианта, границы холста, пользовательские палитры, импорт, история, ответы AI и чистая сборка.
- Все 40 исходников — корректные SVG без растровых вставок. Геометрия оригиналов сохраняется в опубликованной сборке; совпадение всех SHA256 подтверждено чистой сборкой.
- 2160 раскладок для пар предметов, двух детализаций, двух ролей, четырёх форматов и трёх вариантов: объекты в пределах холста, единый масштаб.
- 9072 заливки/обводки во всех вариантах и трёх палитрах: все сопоставлены с разрешёнными цветовыми ролями; фоновые элементы используют только фоновые роли.
- В реальном браузере: сборка, неизвестный предмет без потери работы, перемещение мышью, маркеры размера и поворота, дубликат, удаление, порядок/роли слоёв, пользовательская палитра JSON, S/L, форматы, отмена/повтор и восстановление после перезагрузки.
- Регрессия асинхронного подбора: отложенный AI-ответ не заменяет новый проект.
- Desktop 1440px и mobile 390px: доступные элементы управления, без горизонтального переполнения после адаптации.
- На публичной версии экспортирован SVG с 104 path-узлами и нулём растровых image. Повторный разбор SVG проходит без ошибок; служебных элементов выделения нет.
- Публичная ссылка проверена в отдельном контексте браузера без авторизации: HTTP 200, редактор и библиотека доступны.
- Локальный живой DeepSeek-запрос «Вырастить идею» корректно вернул лампу, цветы и книгу с объяснением. На опубликованном сайте доступность зависит от серверной настройки; проверяется `/api/status`.

Ограничения: библиотека фиксированная (10 смысловых объектов), локальный подбор ограничен темами и простыми языковыми конструкциями; автораскладка даёт редактируемую отправную композицию, а не гарантированное художественное решение для любой пары. Нет совместного редактирования и серверного хранения проектов. Лимиты AI действуют на экземпляр функции, а не как глобальная квота расходов.
