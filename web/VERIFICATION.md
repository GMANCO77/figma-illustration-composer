# Проверка веб-версии

Проверено 20 ноября 2026 года по времени Бангкока.

- 42 автоматических проверок: названия со склонениями, неизвестные предметы, исключения, три варианта, границы холста, пользовательские палитры, импорт, история, ответы AI и чистая сборка.
- Все 40 исходников — корректные SVG без растровых вставок. Геометрия оригиналов сохраняется в опубликованной сборке; совпадение всех SHA256 подтверждено чистой сборкой.
- 2160 раскладок для пар предметов, двух детализаций, двух ролей, четырёх форматов и трёх вариантов: объекты в пределах холста, единый масштаб.
- 9072 заливки/обводки во всех вариантах и трёх палитрах: все сопоставлены с разрешёнными цветовыми ролями; фоновые элементы используют только фоновые роли.
- В реальном браузере: сборка, неизвестный предмет без потери работы, перемещение мышью, маркеры размера и поворота, дубликат, удаление, порядок/роли слоёв, пользовательская палитра JSON, S/L, форматы, отмена/повтор и восстановление после перезагрузки.
- Регрессия асинхронного подбора: отложенный AI-ответ не заменяет новый проект.
- Desktop 1440px и mobile 390px: доступные элементы управления, без горизонтального переполнения после адаптации.
- На публичной версии экспортирован SVG с 104 path-узлами и нулём растровых image. Повторный разбор SVG проходит без ошибок; служебных элементов выделения нет.
- Публичная ссылка проверена в отдельном контексте браузера без авторизации: HTTP 200, редактор и библиотека доступны.
- Локальный живой DeepSeek-запрос «Вырастить идею» корректно вернул лампу, цветы и книгу с объяснением. На опубликованном сайте DeepSeek подключён и проверен на трёх живых запросах: метафора роста идеи, объединение знаний с исключением телефона и неподдерживаемый конкретный предмет. `/api/status` возвращает available=true.

Ограничения: библиотека фиксированная (10 смысловых объектов), локальный подбор ограничен темами и простыми языковыми конструкциями; автораскладка даёт редактируемую отправную композицию, а не гарантированное художественное решение для любой пары. Нет совместного редактирования и серверного хранения проектов. Лимиты AI действуют на экземпляр функции, а не как глобальная квота расходов.

## Финальная проверка перед отправкой работодателю

20 ноября 2026 года проверена актуальная опубликованная GitHub Pages версия без авторизации. Исправлены молчаливое ограничение списка шестью предметами и остановка загрузки при кратковременном503 от GitHub. Теперь явный список сохраняет все10 доступных предметов; статические GET и проверка доступности сервера имеют ограниченные повторы. Платный POST к модели автоматически не повторяется.

Повторный полный браузерный сценарий: HTTP200 у сайта,40 из40 SVG загружены;3 реальных запроса DeepSeek через Vercel вернули200 (2 поддерживаемые метафоры и1 неподдерживаемый конкретный предмет); явное исключение телефона соблюдено. Проверены неизвестные предметы без потери работы, положение/поворот, дубликат/удаление, undo/redo, фоновые роли, пользовательская палитра, детализацииS/L,4 формата,3 раскладки, автосохранение, переносимый JSON-проект и экспорт. В этом проходе ошибок консоли, запросов с ошибочнымHTTP-статусом и сетевых отказов не было. Мобильный viewport390px — без горизонтального переполнения.

Экспортированный файл повторно разобран как XML:104 path,0 image; нет служебных атрибутов и внешних ссылок. Отдельно смоделирован503 у одногоSVG — библиотека загрузилась после одного повтора. Смоделирован503 у AI-сервера — прежняя работа сохранена, показано объяснение, ручной режим доступен; платныйPOST выполнен ровно один раз. Материальные ограничения сохраняются: защита от частых AI-запросов и баланс DeepSeek; отсутствие ошибок в проверенном сценарии не отменяет лимитов внешних сервисов.
