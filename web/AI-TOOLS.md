# AI-инструменты

- OpenAI Codex — анализ задания и существующего плагина, разработка веб-версии, проверки и независимая проверка кода.
- DeepSeek API, модель `deepseek-flash` — необязательный подбор существующих ID предметов по смыслу пользовательской темы. Серверная интеграция реализована и проверена локально живым запросом. Публичный сайт активирует её только при наличии серверной настройки.

AI не генерирует иллюстративные объекты, SVG-контуры, фоновые формы или изменённые версии рисунков. Все 40 вариантов взяты из исходной библиотеки Figma. Локальная компоновка, перекраска и экспорт выполняются обычным кодом. Бесплатный резервный подбор по темам — словарный алгоритм; он не выдаётся за языковую модель.

В API DeepSeek передаются тема и текстовый каталог названий/тегов. Изображения, SVG и содержимое Figma не отправляются.
