# Собрано — конструктор векторных иллюстраций

**Работающая веб-версия:** https://gmanco77.github.io/figma-illustration-composer/

Открывается в браузере без регистрации и установки Figma. Создана на основе исходной библиотеки тестового задания: 10 объектов, 40 настоящих вариантов S/L × главный/фоновый. Новые иллюстративные формы не генерируются.

## Как проверить

1. В режиме «По объектам» введите `Книга, лампа и ручка` и нажмите «Собрать композицию».
2. Выберите одну из трёх композиций. Перетащите объект, измените масштаб или поворот, назначьте фоновую роль, поменяйте порядок слоёв.
3. Измените формат, детализацию S/L и палитру. Через кнопку загрузки рядом с палитрами можно импортировать JSON из `examples/palette.json`.
4. Нажмите «Скачать SVG». Полученный файл состоит из исходных векторных объектов и остаётся редактируемым.

В режиме «По идее» бесплатно работает локальный подбор по темам. Примеры: `Вырастить идею`, `Сила команды`, `Обучение без телефона`. Это ограниченный словарь, а не универсальное понимание текста. На публичном сайте включён DeepSeek: переключатель «Умный подбор» анализирует свободные метафоры. Состояние подключения проверяется через `/api/status` и честно отображается в интерфейсе.

Неизвестные компоненты показываются отдельно; частично распознанный список не заменяет текущую работу. Клавиши: стрелки — сдвиг, Shift+стрелка — сдвиг на 10, Delete — удаление, Ctrl/Cmd+D — дубликат, Ctrl/Cmd+Z — отмена, Ctrl/Cmd+Shift+Z — повтор. Изменения сохраняются в браузере. Проект можно выгрузить и открыть как JSON через меню «Проект».

## Локальный запуск

Node.js 22.16+. Сторонние библиотеки не требуются.

```sh
npm run build
npm start
```

Откройте http://127.0.0.1:4173. Первая сборка распаковывает `assets.bundle.gz` — это сжатый пакет оригинальных SVG, манифеста и проверки происхождения. SHA256 исходных файлов записаны в `assets/verification.json`. В архиве передачи также есть распакованная библиотека.

```sh
npm test
```

## DeepSeek

Для собственного запуска задайте `DEEPSEEK_API_KEY` на сервере, модель — `deepseek-flash`. Локально можно создать `.env` по примеру `.env.example` и выполнить:

```sh
node --env-file=.env scripts/serve.mjs
```

В Vercel ключ задаётся только в защищённых переменных проекта. Никогда не помещайте ключ в браузерный код. Без ключа редактор продолжает работать с локальным подбором. API DeepSeek оплачивается отдельно от бесплатного размещения.

Передаются только пользовательская тема и текстовый каталог. SVG и изображения провайдеру не отправляются. Ответ проверяется на известные ID, повторы, количество объектов и простые явные исключения. Есть тайм-аут, кэш и ограничение запросов в пределах экземпляра функции. Это защита небольшого демо, а не глобальная квота расходов: перед широким публичным запуском нужны распределённые лимиты и мониторинг бюджета.

## Материалы

- `ARCHITECTURE.md` — устройство библиотеки, подбор, компоновка и экспорт.
- `AI-TOOLS.md` — использованные AI-инструменты.
- `VERIFICATION.md` — выполненные проверки и ограничения.
- `examples/` — три готовых SVG и пользовательская палитра.
- `tests/` — проверка логики, сервера и сборки с оригинальными файлами.

Сама библиотека принадлежит её исходным правообладателям и предоставлена для тестового задания. Наличие файлов в этом репозитории не означает отдельного разрешения использовать её в других проектах.
